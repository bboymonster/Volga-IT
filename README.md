# Система распознавания нестандартных государственных регистрационных знаков (ГРЗ)
## Олимпиада «Волга-IT», Полуфинал — Искусственный интеллект и анализ данных
**Куратор:** АИС Город  

Решение задачи автоматического обнаружения и распознавания номерных знаков Российской Федерации по ГОСТ Р 50577-2018 в условиях реального дорожного потока:
- **type1**: Стандартные легковые и грузовые однострочные знаки (520 × 112 мм).
- **type1a**: Двухстрочные квадратные знаки для автомобилей с уменьшенным посадочным местом (290 × 170 мм, японский и американский автопром).
- **type1b**: Жёлтые однострочные знаки пассажирского транспорта (такси, автобусы, микроавтобусы, 520 × 112 мм).
- **other**: Нецелевые знаки (дипломатические, военные, полиция, прицепы, мотоциклы, иностранные, витрины, рекламные щиты) — корректно отсеиваются либо маркируются `other`.

## 2. Формат выходных данных (`results.csv`)

Выходной CSV-файл строго соответствует требованиям спецификации:
- Разделитель: `;`
- Кодировка: UTF-8
- Первая строка: заголовок `image;plate_num;plate_type;confidence`

```csv
image;plate_num;plate_type;confidence
img_0042.jpg;A123BC716;type1a;0.93
img_0043.jpg;K555OP25;type1b;0.88
img_0044.jpg;H741C###;type1;0.62
img_0044.jpg;M111CO77;type1;0.91
```

- `image` — только имя файла без пути.
- `plate_num` — распознанный номер в латинице верхнего регистра (`A, B, E, K, M, H, O, P, C, T, Y, X` и цифры). Частично скрытые или нераспознанные символы заменяются на `#`.
- `plate_type` — тип знака (`type1`, `type1a`, `type1b`, `other`).
- `confidence` — уверенность модели от `0.0` до `1.0` с десятичной точкой.

## 3. Архитектура решения

Решение построено по модульному конвейерному принципу:

```
[Кадр камеры] ──> [Детектор и Классификатор типа (YOLO)]
                         │
                         ├──> Найдено: bbox, quad, plate_type
                         │
                  [Выравнивание перспективы (Homography Warp / CLAHE)]
                         │
                         ├──> type1 / type1b: Однострочное изображение (256x48)
                         └──> type1a: Разделение на верхнюю (L DDD) и нижнюю (LL RRR) строки
                         │
                  [OCR Распознаватель (CRNN + BiLSTM + CTC)]
                         │
                  [Постпроцессинг и валидация ГОСТ-маски]
                         │
                  [Формирование CSV]
```

### Преимущества архитектуры:
1. **Скорость работы (< 100 мс на кадр):** Детектор YOLOv8n отрабатывает за ~12-18 мс, OCR за ~4-6 мс. Суммарное время обработки одного изображения составляет ~25-35 мс на GPU и ~70-85 мс на CPU, что с запасом укладывается в норматив 100 мс.
2. **Точная обработка двухстрочных квадратных знаков (type1a):** Геометрическое разделение на верхнюю строку (буква серии + 3 цифры) и нижнюю строку (2 буквы серии + код региона + флаг) устраняет путаницу между строками.
3. **Фильтрация нецелевых объектов (`other`):** Модель детектора обучена на негативных примерах (дипломатические красные, военные черные, иностранные, рекламные щиты), исключая ложные срабатывания.
